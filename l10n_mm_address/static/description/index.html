Myanmar Address Localization for Odoo 19

Complete Myanmar administrative address hierarchy with MIMU P-code integration — State/Region, District, Township, Town, Ward/Village Tract, and Postal Code built into Odoo contacts with cascading dropdowns and auto-fill.

Odoo 19 Localization Contacts CRM Ready HR Ready Myanmar Address Data

Main Features

Full Address Hierarchy

State/Region → District → Township → Town → Ward/Village Tract with cascading dropdowns on every contact form.

P-Code Auto-fill

Enter a MIMU P-code to instantly populate the full address hierarchy — State, District, Township, Town, and Ward.

Myanmar Language Names

All records carry a name_mm field. Toggle Myanmar script display from Settings → Contacts.

Computed Full Address

The l10n_mm_full_address computed field assembles the complete Myanmar address string for display and reporting.

Map View Support

Partner locations displayed on the map using township-level latitude/longitude coordinates (Enterprise).

Optional Extensions

Companion modules l10n_mm_address_crm and l10n_mm_address_hr extend Myanmar address fields to CRM and HR.

Configuration Steps

1

Install the module

Place l10n_mm_address in your custom addons path, restart Odoo, update the Apps list, and install.

2

Open a contact form

Set Country to Myanmar to reveal the Myanmar address fields on the contact form.

3

Use cascading dropdowns or P-Code

Select State → District → Township → Town → Ward in sequence, or enter a MIMU P-code to auto-fill the entire hierarchy.

4

Enable Myanmar language display (optional)

Go to Settings → Contacts → Use Myanmar Language to toggle Myanmar script names across all address fields.

5

Browse master data

Access all address records via Contacts → Configuration → Myanmar Localization.
